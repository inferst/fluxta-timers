# Fluxta Timers

A Fluxta plugin with named Timers and Stopwatches for scenario builders:
countdowns that fire an Event when they run out (once or on a repeating
schedule), and stopwatches that count time across pauses.

Work in progress — the first slice is tracked in
[#1](https://github.com/inferst/fluxta-timers/issues/1).
